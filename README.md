# Structured Literature Synthesis: LASR Labs Workshop

A 30-minute workshop that teaches one workflow: how to go from "AI summarized these papers for me" to a synthesis you can actually trust, saved as a note in a linked vault that keeps paying off for the rest of a 13-week fellowship instead of disappearing into a chat log.

This repo is the worked example the work test asks for, and it's also a real, working Obsidian vault. Clone it and open this folder directly in Obsidian to see the notes, tags, and `[[wikilinks]]` connect (graph view included). Every file also reads fine as plain markdown on GitHub if you don't use Obsidian, nothing here depends on it.

## How to use this

- **Just reading:** start at [`03 Worked Example/Research Question.md`](<03 Worked Example/Research Question.md>) and follow the links from there.
- **Opening as a vault:** clone the repo, open this folder in Obsidian (`Open folder as vault`), and click through the graph view to see how the three papers, the raw extraction, the verification log, and the synthesis connect.
- **Running the workshop yourself:** everything in `01 Prompts/` and `02 Template/` is the actual take-home kit, copy it into your own vault and run it on your own papers.
